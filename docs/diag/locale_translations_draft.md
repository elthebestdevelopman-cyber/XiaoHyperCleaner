# Черновик переводов — hi / pt / id (локали вне текущего кода)

Назначение: источник истины для спорных строк `semantic_steps.json` в
локалях, которых нет в текущих `searchTexts` (хинди, португальский,
индонезийский). Переводы уже внесены в `semantic_steps.json`; этот файл —
реестр спорных мест и правило их правки.

Правило: спорные строки правим только по дампам реальных прогонов
(снимки `DiagnosticSnapshotManager`). Гейт при несовпадении даёт
`skipped=low_confidence`/`switch_not_found`, а не угадывание текста.

## Таблица спорных переводов

| Шаг / строка | Локаль | Текущее значение в `semantic_steps.json` | Статус |
|---|---|---|---|
| `msa` screenMarkers «Авторизация и отзыв» | hi | «प्राधिकरण और प्रत्याहरण» | ⚠️ verify: проверить по дампу экрана «Авторизация и отзыв» на hi-прошивке; возможен вариант «अधिकृत करना और निरसन» |
| `ux_program` название программы | pt | «Programa de Experiência do Usuário» | ⚠️ verify: капитализация (возможно «Programa de experiência do usuário»); правим по дампу |
| `themes` фразы согласия (согласен / принять) | hi | полные фразы согласия на хинди | ⚠️ verify: полный текст кнопок согласия берём из дампа consent-стены на hi-устройстве |
| `themes` фразы согласия | pt | полные фразы согласия на pt-BR | ⚠️ verify: то же для pt-устройства |
| `themes` фразы согласия | id | полные фразы согласия на индонезийском | ⚠️ verify: то же для id-устройства |

## Примечания

- Все записи ⚠️ verify закрываются после первого успешного прогона на
  соответствующей локали: строка сверяется с текстом узла из дампа,
  правка вносится в `semantic_steps.json`, статус снимается.
- До верификации эти строки не блокируют запуск: `SemanticGate` вернёт
  `low_confidence` и шаг пропустится (`skipped`), поведение деградирует
  безопасно, без ложных нажатий.
- `locale_translations_draft.md` не является рантайм-источником: данные
  читаются только из `semantic_steps.json` через `SemanticCatalog`.
