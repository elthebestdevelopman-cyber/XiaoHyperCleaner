## 🚨 Как сообщить об уязвимости

### НЕ создавайте публичный Issue для уязвимостей!

Это может подвергнуть риску других пользователей до того, как уязвимость будет исправлена.

### Правильный способ:

1. **Напишите на email:** [elthebestdevelopman@proton.me](mailto:elthebestdevelopman@proton.me)
2. **Или используйте GitHub Security Advisories:**
   - Перейдите в [Security → Advisories](https://github.com/elthebestdevelopman-cyber/XiaoHyperCleaner/security/advisories)
   - Нажмите "Report a vulnerability"
   - Заполните форму

### Что указать в репорте:

```
1. Версия приложения: 1.0-beta2
2. Устройство и прошивка: Xiaomi Redmi Note 10 Pro, MIUI 14.0.4
3. Android: 13
4. Описание уязвимости:
   [подробное описание]
5. Шаги воспроизведения:
   1. ...
   2. ...
6. Потенциальное влияние:
   [что может сделать злоумышленник]
7. Доказательство концепции (PoC):
   [код, скриншоты, видео]
8. Предлагаемое исправление (опционально):
   [ваши идеи]
```

### Сроки реакции:

| Этап | Срок |
|------|------|

## 🔍 Что считается уязвимостью

Мы серьёзно относимся к следующим типам проблем:

### Критичные
- 🔴 Выполнение произвольного кода через ADB-команды
- 🔴 Утечка пользовательских данных через логи
- 🔴 Возможность повышения привилегий
- 🔴 Обход механизмов отката

### Высокие
- 🟠 Доступ к системным настройкам без ведома пользователя
- 🟠 Сохранение чувствительных данных в открытом виде
- 🟠 Возможность отключить критичные системные сервисы без подтверждения

### Средние
- 🟡 Маскировка данных в логах неполная
- 🟡 Отсутствие проверки входных данных в диалогах
- 🟡 Возможность обойти предупреждение о DNS

### Низкие
- 🟢 Информация о версии приложения в логах
- 🟢 Отсутствие rate limiting на кнопки

## ❌ Что НЕ считается уязвимостью

Следующее **не является** уязвимостью безопасности:

- ✅ Приложение требует разрешений accessibility и overlay — это **необходимо** для работы
- ✅ Приложение подключается к ADB через 127.0.0.1 — это **локальное** соединение, не сетевое
- ✅ Приложение отключает системные пакеты — это **основная функция**, пользователь сам это инициирует
- ✅ Отсутствие HTTPS для донат-ссылок — они открываются в WebView с проверенными URL
- ✅ Приложение распространяется вне Google Play — это **не баг**, а следствие политики Google

**Если сомневаетесь** — всё равно напишите, лучше перестраховаться.

## 🛡 Принятые меры безопасности

### 1. Локальность всех операций

- Все ADB-команды выполняются через `127.0.0.1` — **только локально**
- Нет сетевых запросов на внешние серверы (кроме донат-ссылок)
- Нет аналитики, трекеров, сбора данных

### 2. Маскировка логов

Все чувствительные данные в `xhc.log` маскируются через `LogMasker`:
- IP-адреса (кроме 127.0.0.1) → `x.x.x.x`
- Длинные hex-строки → `[MASKED]`
- Пути к пользовательским данным → `/data/user/*/`
- Значения системных настроек → `[VALUE]`

### 3. Подтверждение действий

Все потенциально опасные действия требуют явного подтверждения:
- Откат изменений → диалог
- Перезагрузка → диалог
- Включение DNS-фильтра → предупреждение о последствиях

### 4. Транзакционный rollback

При любом сбое оптимизации:
- Все применённые изменения откатываются автоматически
- DNS возвращается к исходному значению
- Пакеты включаются обратно
- Пользователь видит детальный отчёт о провале

### 5. Открытый код

- Исходный код полностью открыт
- Каждая ADB-команда логируется
- Любой может проверить что делает приложение

### 6. Ограничение разрешений

- Приложение использует только необходимые разрешения:
  - `INTERNET` — для донат-ссылок в WebView
  - `SYSTEM_ALERT_WINDOW` — для оверлея с прогрессом
  - Accessibility Service — для автоматизации UI
- Нет доступа к контактам, SMS, камере, микрофону

## 📢 Политика раскрытия

### Координированное раскрытие

Мы придерживаемся практики **координированного раскрытия**:

1. Вы сообщаете об уязвимости приватно
2. Мы подтверждаем получение и оцениваем критичность
3. Мы разрабатываем и тестируем исправление
4. Мы выпускаем обновление
5. **Через 7 дней после выпуска обновления** публикуется Security Advisory с описанием уязвимости (без технических деталей до патча)

### Награды

Мы не можем предложить денежное вознаграждение (проект некоммерческий), но:

- 🏆 Ваше имя будет указано в Security Advisory (если хотите)
- 🏆 Ваше имя будет упомянуто в CHANGELOG
- 🏆 Вы получите ранний доступ к исправленной версии
