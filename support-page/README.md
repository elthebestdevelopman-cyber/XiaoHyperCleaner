# support-page — статическая страница донатов XiaoHyperCleaner

Лёгкая статическая страница для приёма донатов. Без сборки, без зависимостей
(кроме QR-библиотеки с CDN), без cookies/аналитики/трекинга.

## Развёртывание

Скопируйте содержимое этой папки в репозиторий GitHub Pages (ветка/папка,
отдающая сайт), например в `support/`. Итоговый адрес:
`https://elthebestdevelopman-cyber.github.io/support/`.

Все подключения в `index.html` — **относительные** (без ведущего слэша),
поэтому папку можно класть на любой подпуть.

## Файлы

| Файл | Назначение |
|------|------------|
| `index.html` | Разметка: crypto, Russia, Telegram Stars, футер |
| `style.css` | Mobile-first стили, тёмная/светлая тема (`prefers-color-scheme`), акцент `#4FC3F7` |
| `config.js` | **Единственное** место с изменяемыми данными (ссылки, адреса, telegram, заголовок) |
| `i18n.js` | Переводы UI на 7 языков (ru, en, es, zh, hi, pt, id) |
| `app.js` | Логика: автоопределение языка, переключатель, QR, копирование |
| `favicon.svg` | Иконка |

## Языки

- Автоопределение по `navigator.language` (префикс: `es-ES` → `es`).
- Ручной переключатель (7 языков), выбор сохраняется в `localStorage` (`xhc_lang`).
- Fallback — `en`.

## QR

Генерируется на клиенте через CDN `qrcode@1.5.3`:
- TON: кодирует `"ton://transfer/" + CONFIG.tonUniversal`.
- TRC-20: кодирует сырой `CONFIG.usdtTrc20`.

При недоступности CDN QR просто не отрисуется — остальная страница работает.

## Правки данных

Меняйте **только** `config.js`. Адреса, ссылки и telegram-ник берутся оттуда;
в `index.html`/`app.js` они не захардкожены.
