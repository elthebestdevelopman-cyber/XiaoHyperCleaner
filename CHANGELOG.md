## [1.0-beta3] - 2026-08-21

### Добавлено
- 🆕 **Simple Mode** — новый режим автоматизации через Accessibility Service (без Shizuku/ADB/Wi-Fi)
  - 16 автоматических шагов по официальной инструкции сообщества Xiaomi (обновлено 29.07.2026)
  - Интерактивные подсказки: пульсирующие стрелки поверх системных настроек
  - Пошаговое ведение пользователя через экраны MIUI/HyperOS
- 🆕 **Ядро приватности** (5 шагов):
  - Системный сервис MSA (отзыв разрешения в «Авторизация и отзыв»)
  - Системные рекомендации (пункт «Получать рекомендации»)
  - Персонализация контента (системные службы)
  - Программа улучшения UX (телеметрия)
  - Системная аналитика
- 🆕 **Уведомления системных приложений** (10 шагов):
  - GetApps, Темы, Mi Music, Mi Браузер, Mi Видео
  - Игровой центр, Лента виджетов (App Vault, `com.miui.personalassistant`)
  - Карусель обоев (`com.miui.android.fashiongallery`) — экран блокировки
  - Проводник, Xiaomi Service Framework
- 🆕 **Идентификатор персонализации Google** — сброс/отключение
- 🆕 **TestActivity** — автоматическая проверка работоспособности Accessibility Service
  - Тестовый клик по кнопке, broadcast результата, таймаут 5 сек
  - Fallback-кнопка для ручного подтверждения
- 🆕 **Battery Optimization phase** — запрос снятия ограничений HyperOS для стабильной работы сервиса
- 🆕 **Restricted Settings Screen** — пошаговая инструкция для разблокировки ограниченных настроек на Android 13+ sideload
- 🆕 **Permission Fallback Dialog** — вместо сброса Simple Mode при неудаче:
  - «Попробовать ещё раз» (сброс счётчика)
  - «Открыть настройки» (переход вручную)
  - «Отменить оптимизацию» (полный сброс)
- 🆕 **Диалог согласия на Accessibility** с явным подтверждением (compliance с магазинами)

### Изменено
- 🔄 **Overlay Service** переписан:
  - Персистентный режим (не исчезает при возврате в MainActivity)
  - Пульсирующая стрелка (72sp + alpha-анимация)
  - `FLAG_NOT_TOUCHABLE` — пользователь взаимодействует с настройками сквозь подсказку
  - AutoSize-текст карточек — автоматически масштабируется под любой экран
- 🔄 **MainActivity рефакторинг**:
  - Все 17 диалогов вынесены в `MainDialogsHost` (сокращение на ~55%)
  - Вертикальная компоновка кнопок в fallback-диалоге (`fillMaxWidth` + `softWrap`)
  - Убраны лишние логи в `onResume`/`onPause`
- 🔄 **Simple Mode Controller**:
  - Новая машина состояний: `INACTIVE → RESTRICTED_SETTINGS → OVERLAY → ACCESSIBILITY → TEST_CLICK → BATTERY_OPTIMIZATION → STEPS → DONE`
  - До 3 автоповторов на каждом шаге с диагностикой причины
  - Graceful degradation: пропуск шагов, недоступных на текущей прошивке
- 🔄 **Обновлены строки локализации RU/EN**:
  - 35+ новых строк для Simple Mode, тестов, fallback-диалогов
  - Пользовательские тексты нейтральные (без слов, блокирующих публикацию в магазинах)
- 🔄 **Подготовка к DeviceDetector** — определение производителя (Xiaomi/Huawei/Samsung) для будущей фильтрации шагов

### Исправлено
- 🐛 **Критический баг TEST_CLICK** — бесконечный цикл на Xiaomi и Huawei:
  - Защита от двойного запуска `TestActivity` (флаг `testActivityLaunched`)
  - Защита receiver от множественных broadcast'ов (проверка `finished`)
  - Корректная обработка возврата из TestActivity в `MainActivity.onResume`
- 🐛 **Стрелки оверлея исчезали мгновенно** — убран авто-стоп `OverlayService` при активном Simple Mode
- 🐛 **Текст кнопок обрезался** («Откр ыть наст») на маленьких экранах — вертикальная компоновка + `softWrap`
- 🐛 **`simpleModeActive` не обновлялся** в `MainViewModel.mergeSimpleState` — теперь всегда отражает реальное состояние
- 🐛 **Ложное срабатывание TEST_CLICK** при возврате из recents меню — проверка `awaitingTestClick` перед чтением результата
- 🐛 **Race condition** при быстром двойном нажатии на «Запустить шаг» — защита в `startCurrentStep`
- 🐛 **`@Composable` ошибки компиляции** в `MainDialogsHost` — вынос `stringResource` из лямбд
- 🐛 **`AlertDialog` требовал обязательных `confirmButton`/`dismissButton`** — оставлены пустыми, реальные кнопки внутри `text`

### Технические детали
- Kotlin 2.4.10
- Compose BOM 2026.08.00
- AGP 9.3.1 (built-in Kotlin)
- compileSdk 37, targetSdk 36, minSdk 28
- JDK 21
- 16 шагов Simple Mode (ранее 12)
- `MainViewModel` сокращён на ~55% строк после рефакторинга
- 29 unit-тестов проходят

### Подтверждённые устройства
- ✅ Xiaomi 22021211RG (MIUI/HyperOS, Android 14) — все 16 шагов проходят
- ✅ Huawei ADY-LX9 (EMUI, Android 12) — Simple Mode флоу полностью проходит
  (автоматизация шагов на Huawei будет добавлена в будущих версиях)

## [1.0-beta2] - 2026-08-15

### Добавлено
- 🆕 **Онбординг** при первом запуске (3 коротких экрана)
- 🆕 **Диалог опций** перед оптимизацией — можно выбрать включать ли DNS-фильтр
- 🆕 **DNS-фильтр (опционально)** — блокировка доменов через AdGuard DNS
- 🆕 **Предупреждение о DNS** — объяснение возможного замедления интернета
- 🆕 **Транзакционный rollback** — при любом сбое изменения откатываются автоматически
- 🆕 **Детальный отчёт** после оптимизации:
  - Сколько пакетов отключено
  - Сколько параметров применено
  - Какие действия не удались
- 🆕 **Улучшенный flow restricted/forbidden settings** для Android 13+ sideload
- 🆕 **Сплеш-экран** с робокотом и клубком ниток
- 🆕 **Шаринг логов** — кнопка «Поделиться логом» в меню ⋮
- 🆕 **WebView для донатов** — ЮMoney и CloudTips открываются внутри приложения

### Изменено
- 🔄 Обновлён `OptimizationEngine` с поддержкой `OptimizationReport`
- 🔄 Убрана проверка `restrictedSettingsAllowed()` через AppOpsManager (не работает на MIUI)
- 🔄 Restricted dialog показывается только при реальной блокировке системы
- 🔄 Улучшено логирование во всех ключевых компонентах
- 🔄 Обновлены строки локализации RU/EN

### Исправлено
- 🐛 Зацикливание на restricted dialog при возврате из настроек
- 🐛 Дублирование `openAppInfoSettings` в MainActivity
- 🐛 `Conflicting declarations` в MainViewModel (два companion object)
- 🐛 `Unresolved reference 'VerificationResult'` в OptimizationEngine
- 🐛 Деструктуризация Map в rollback
- 🐛 Тесты обновлены под новый API `OptimizationReport`

### Технические детали
- Kotlin 2.4.10
- Compose BOM 2026.06.01
- AGP 9.3.1 (built-in Kotlin)
- 29 unit-тестов проходят

## [1.0-beta1] - 2026-08-10

### Добавлено
- Первый публичный релиз
- Базовая оптимизация через локальный ADB (127.0.0.1)
- 4 метода оптимизации:
  1. Системные параметры (анимации, фоновые процессы)
  2. Отключение сервисов аналитики
  3. Фейковая смена региона
  4. Отключение системных служб
- Accessibility-цепочка для автоматической настройки:
  - Включение оверлея
  - Открытие настроек разработчика
  - Включение беспроводной отладки
  - Нажатие «Разрешить»
- Оверлей с прогрессом выполнения
- Диалоги подтверждения для всех действий
- Откат изменений (restore)
- Перезагрузка через ADB (shell reboot)
- Локализация RU и EN
- Тёмная тема (следует за системной)
- Бета-логирование с маскировкой данных (`LogMasker`)
- Шаринг лога через FileProvider
- WebView для ЮMoney и CloudTips
- 19 unit-тестов

### Известные ограничения
- Кнопка «Перезагрузить» требует беспроводную отладку
- На устройствах не Xiaomi оптимизация может не завершиться
- Restricted settings на Android 13+ требуют ручного разрешения

## Ключевые изменения по сравнению с beta2

| Время настройки | 2-5 минут (ADB/Wi-Fi) | **30-60 секунд** (только тапы) |
