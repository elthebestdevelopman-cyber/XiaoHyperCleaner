## [1.0-beta2] - 2025-01-15

### Добавлено
- 🆕 **Онбординг** при первом запуске (3 коротких экрана)
- 🆕 **Диалог опций** перед оптимизацией — можно выбрать включать ли DNS-фильтр
- 🆕 **DNS-фильтр (опционально)** — блокировка рекламных доменов через AdGuard DNS
- 🆕 **Предупреждение о DNS** — объяснение возможного замедления интернета
- 🆕 **Транзакционный rollback** — при любом сбое изменения откатываются автоматически
- 🆕 **Детальный отчёт** после оптимизации:
  - Сколько пакетов отключено
  - Сколько параметров применено
  - Какие действия не удались
- 🆕 **Улучшенный flow restricted/forbidden settings** для Android 13+ sideload
- 🆕 **Сплеш-экран** с робокотом и клубком ниток
- 🆕 **Шаринг логов** — кнопка «Поделиться логом» в меню ⋮
- 🆕 **WebView для донатов** — ЮMoney и CloudTips открываются внутри приложения

### Изменено
- 🔄 Обновлён `OptimizationEngine` с поддержкой `OptimizationReport`
- 🔄 Убрана проверка `restrictedSettingsAllowed()` через AppOpsManager (не работает на MIUI)
- 🔄 Restricted dialog показывается только при реальной блокировке системы
- 🔄 Улучшено логирование во всех ключевых компонентах
- 🔄 Обновлены строки локализации RU/EN

### Исправлено
- 🐛 Зацикливание на restricted dialog при возврате из настроек
- 🐛 Дублирование `openAppInfoSettings` в MainActivity
- 🐛 `Conflicting declarations` в MainViewModel (два companion object)
- 🐛 `Unresolved reference 'VerificationResult'` в OptimizationEngine
- 🐛 Деструктуризация Map в rollback
- 🐛 Тесты обновлены под новый API `OptimizationReport`

### Технические детали
- Kotlin 2.4.10
- Compose BOM 2026.06.01
- AGP 9.3.1 (built-in Kotlin)
- 29 unit-тестов проходят

## [1.0-beta1] - 2025-01-01

### Добавлено
- Первый публичный релиз
- Базовая оптимизация через локальный ADB (127.0.0.1)
- 4 метода оптимизации:
  1. Системные параметры (анимации, фоновые процессы)
  2. Отключение сервисов аналитики
  3. Фейковая смена региона
  4. Отключение рекламных служб
- Accessibility-цепочка для автоматической настройки:
  - Включение оверлея
  - Открытие настроек разработчика
  - Включение беспроводной отладки
  - Нажатие «Разрешить»
- Оверлей с прогрессом выполнения
- Диалоги подтверждения для всех действий
- Откат изменений (restore)
- Перезагрузка через ADB (shell reboot)
- Локализация RU и EN
- Тёмная тема (следует за системной)
- Бета-логирование с маскировкой данных (`LogMasker`)
- Шаринг лога через FileProvider
- WebView для ЮMoney и CloudTips
- 19 unit-тестов

### Известные ограничения
- Кнопка «Перезагрузить» требует беспроводную отладку
- На устройствах не Xiaomi оптимизация может не завершиться
- Restricted settings на Android 13+ требуют ручного разрешения
